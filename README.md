# To-y-daftari
Daftar (To'yona hisobi): Kim qancha to'yona bergani va kimga qancha to'yona berilganini aniq va muvozanatli (balans) hisoblab boradi.  Mehmonlar ro'yxati: Mehmonlar soni va ularning kelish holatini belgilash imkoniyati.  Byudjet va Xarajatlar: To'y xarajatlarini  va to'langan/qolgan summalar hisobini yuritadi.Tez va osson yuklab oling !
